# ISAN — คลังวงจร

คลังวงจรสำเร็จรูปสำหรับ **Schematic Studio** (FPGA Ecosystem) — เปิดดู เลือกแบบ แล้วคัดลอกไปวางในโปรแกรมหลัก

**โปรแกรมนี้ไม่ได้สร้างวงจร** ทุกชิ้นในคลังถูกสร้างไว้ล่วงหน้าและตรวจแล้ว เก็บเป็นไฟล์ข้อมูลใน `data/`
ตัวโปรแกรม (`index.html`, `isan.js`, `isan.css`) มีหน้าที่แค่ อ่านรายการจากคลัง → แสดงรูปวงจร / ขา / วิธีที่ตรวจ → คัดลอกข้อมูลวงจรนั้นไปที่ clipboard

## ใช้งาน
1. ดับเบิลคลิก `index.html` (Edge / Chrome) — ไม่ต้องติดตั้ง ไม่ต้องต่อเน็ต
2. เลือกหมวด / ค้นหา → คลิกการ์ด → เลือกแบบ (จำนวนบิต, นับลง, active-low …)
3. กด **คัดลอกไปโปรแกรมหลัก**
4. ใน Schematic Studio (2.8.1 ขึ้นไป) คลิกบนแผ่นตรงที่จะวาง แล้วกด **Ctrl+V**
   - ชิ้นส่วน = มาเป็นบล็อกเดียว พร้อมแผ่นย่อยที่ใช้ และสถานะ "ตรวจแล้ว"
   - บล็อก VHDL = บล็อกพร้อมโค้ด

## ในคลัง
60 ชิ้น 841 แบบ — บวก / ลบ / คูณ / หาร, ALU, เปรียบเทียบ, MUX / DEMUX / Decoder / Encoder, แปลงรหัส, จอ 7-segment,
ไฟ LED / PWM, Flip-flop / Register, ตัวนับ, หารความถี่ (2 … 50,000,000), ปุ่มกด / ขอบสัญญาณ,
อุปกรณ์บนบอร์ด (LCD 16×2, ADC MCP3208, UART, บัซเซอร์), ระบบทั้งแลป (แลป 6, 7), ตรวจจับลำดับบิต (FSM)

## ไฟล์
| | |
|---|---|
| `index.html`, `isan.js`, `isan.css` | ตัวเปิดดู / คัดลอก |
| `data/index.js` | รายการชิ้น หมวด และแบบที่มี |
| `data/items/<ชิ้น>.js` | ข้อมูลวงจรของแต่ละแบบ (รูปแบบ clipboard ของ Schematic Studio) + รูป — โหลดเมื่อเปิดชิ้นนั้น |
