# ISAN — คลังวงจร (FPGA Circuit Library)

โปรแกรมแยกสำหรับสร้างวงจรสำเร็จรูป แล้วคัดลอกไปวางในโปรแกรมหลัก **Schematic Studio** (FPGA Ecosystem)
ทั้งหน้าเป็นหน้าต่างคลัง (หมวด + การ์ด + ค้นหา) แบบเดียวกับในโปรแกรมหลัก ไม่มี AI / หน้าเลือกขา / ลงบอร์ด

## ใช้งาน
1. ดับเบิลคลิก `circuit-library.html` (เปิดใน Edge / Chrome)
2. เลือกหมวดและชิ้นที่ต้องการ: ชิ้นส่วนสำเร็จรูป (ตัวบวก ตัวนับ ตัวหารความถี่ 7-seg …), บล็อก VHDL (LCD, ADC, + − × ÷ % …)
   หรือเครื่องมือ (ตารางความจริง, FSM, ตัวนับ …) — ทุกชิ้นถูกสร้างแล้วจำลองตรวจเทียบแบบอ้างอิงก่อนเสมอ
3. สร้างเสร็จจะขึ้นหน้าผลลัพธ์: รูปวงจร, ขาเข้า/ออก, ตรวจด้วยอะไร และปุ่ม **คัดลอกไปโปรแกรมหลัก**
   - ชิ้นส่วน / เครื่องมือ = ทั้งแผ่นเป็นบล็อกเดียว (พาแผ่นย่อยที่ใช้ไปด้วย)
   - บล็อก VHDL = บล็อกพร้อมโค้ด
   - "ดูวงจรเต็ม / จำลอง" เปิดดูในตัว editor ได้
4. ไปที่โปรแกรมหลัก คลิกบนแผ่นตรงที่จะวาง แล้วกด **Ctrl+V**

ต้องใช้โปรแกรมหลักเวอร์ชันที่วางข้ามหน้าต่างได้ (หลัง 2.8.0, `editor/ux/67-clip.js`)

## พัฒนา
- `vendor/schematic-studio.html` = สำเนา editor ของโปรแกรมหลัก (`vendor/SOURCE.txt` บอกว่ามาจาก commit ไหน)
- `app/head.js` แยก localStorage ของโปรแกรมนี้ (ขึ้นต้น `cl.`) ไม่ให้ทับงานของโปรแกรมหลัก
- `app/10-app.js`, `app/app.css` = ส่วนของคลังวงจร (หน้าคลังเต็มจอ, หน้าผลลัพธ์ + ปุ่มคัดลอก) — editor ยังทำงานอยู่ข้างใต้ (สร้าง/จำลอง/ตรวจ)

```
python3 build.py                                   # สร้าง circuit-library.html
python3 build.py --vendor ../digital-fpga-ecosystem/schematic\&bus2vhdl.html   # อัปเดต editor แล้วสร้างใหม่
python3 build.py --check                           # ตรวจว่า circuit-library.html ตรงกับซอร์ส
```
ห้ามแก้ `circuit-library.html` ตรง ๆ — ถูกเขียนทับทุกครั้งที่ build
